# 60000+ 元素

[运行示例](https://g6.antv.antgroup.com/zh/examples/performance/massive-data/60000/)

[资料索引](/llms.txt)

页面需要一个 `id="container"` 的 DOM 元素。以下为原始示例源码。

## 源码

```js
import { Graph } from '@antv/g6';

fetch('https://assets.antv.antgroup.com/g6/60000.json')
  .then((res) => res.json())
  .then((data) => {
    const graph = new Graph({
      container: 'container',
      animation: false,
      autoFit: 'view',
      data,
      node: {
        style: {
          size: 4,
          batchKey: 'node',
        },
      },
      behaviors: ['zoom-canvas', 'drag-canvas'],
    });

    graph.render();
  });
```
